# PRD Assistant

一组通用、可公开复用的产品需求与 HTML 原型技能，强调可落地规则、PC/H5 响应式实现、安全的网站参考流程，以及截图对比验证。

## 技能

### `prd-assistant`

用于起草、补全和审校 PRD。保留原始分层写法、审校、图片与语言规范，并增量支持：已确认事实/产品判断/假设/开放问题分层、最小追问、规则优先级与冲突消解、可测试验收标准、REQ/RULE/AC 追踪矩阵、非功能适用性判断，以及按任务需要分流到 HTML 原型。

### `html-prototype`

用于创建自包含 HTML 交互原型，支持：

- PC 1440×900/1280×720 与 H5 390×844/360×800 设备矩阵；
- 用户提供截图的脱敏参考，以及模糊内容不猜测的处理；
- 经用户明确授权后，由用户手动登录，再按最小范围观察网站；
- 需求与原型通过稳定功能 ID 关联；
- 固定环境下的基准截图、当前截图和差异图验证。

## 安装

将 `.trae/skills/` 下需要的技能目录复制到支持 `SKILL.md` 的代理工作区对应技能目录。技能文件不依赖特定厂商运行时；若宿主的技能目录约定不同，请按宿主文档调整目录，保留 `SKILL.md` 结构。

```text
.trae/skills/
├── prd-assistant/
│   ├── SKILL.md
│   ├── review-checklist.md
│   ├── 写法指南.md
│   ├── 图片嵌入与截图指南.md
│   └── 语言表述规范.md
└── html-prototype/
    ├── SKILL.md
    └── references/
        ├── site-reference.md
        └── visual-validation.md
```

## 使用示例

```text
请把以下会议记录整理成中等复杂度 PRD，重点写清状态流转、权限、异常和待确认项。
```

```text
请基于这张已脱敏截图制作原创 HTML 原型，同时支持 1440×900 PC 和 390×844 H5，并对关键页面做截图对比验证。
```

```text
请参考我已授权登录的网站。登录由我手动完成；不要保存凭据或个人数据，只总结布局和交互规律，并制作原创原型。
```

## 隐私与版权

- 不收集或保存密码、令牌、Cookie、内部 URL 与个人信息。
- 网站登录和验证码由用户自行完成。
- 对截图和测试数据先脱敏。
- 仅吸收公开方法和通用界面规律，不复制第三方受限制的文本、源码、视觉资产、商标或字体。
- 本仓库文本为面向通用场景的原创重构，不包含特定公司的专有设计体系。

## 验证

运行仓库自带检查脚本：

```powershell
python scripts/validate_skills.py
```

脚本检查技能目录、frontmatter、引用文件、敏感模式和内部绝对路径。它不能替代人工的版权、隐私与产品质量审查。

## 贡献

提交内容应保持通用、原创和可审计。示例使用虚构数据；新增规则需说明触发条件与完成标准。提交前运行验证脚本并人工复核改动。

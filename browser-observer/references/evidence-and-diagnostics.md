# 证据采集与异常诊断

## 证据层级

优先级从高到低：

1. 可重复操作步骤和操作后的结构化快照；
2. 固定视口、固定状态的截图；
3. 页面 URL、标题、可见文案与元素属性；
4. 控制台错误和网络请求状态；
5. 用户口述或无法复现的历史现象。

每项结论至少关联页面、状态和证据来源。单次偶发现象标记为“观察到一次”，不得直接归纳为稳定规则。

## 截图策略

- 先截整页或当前视口基线，再截关键区域和状态变化；
- 文件名建议包含页面、设备、状态和序号，例如 `orders-pc-empty-01.png`；
- PC 和 H5 分别记录，不用缩放后的 PC 图代替 H5；
- 动态时间、头像、姓名、金额、订单号等先遮蔽或使用测试数据；
- 截图只保留任务必要区域；
- 第三方受限制素材只作为内部观察证据，不复制到公开交付物。

## 状态差异

对比前后状态时记录：

- 前置条件；
- 操作；
- URL、标题和关键文案变化；
- 新增、消失、禁用或移动的控件；
- 加载、空、错误、成功和权限反馈；
- 截图或结构差异；
- 是否可重复。

如果工具支持页面快照或截图差异功能，可用于辅助定位，但最终结论仍需人工核对语义变化。

## 控制台诊断

页面空白、组件异常或点击无响应时检查：

- 未捕获的 JavaScript 错误；
- 资源加载失败；
- 跨域、权限或内容安全策略错误；
- 页面警告是否与当前问题直接相关。

只记录与任务相关的错误类型、出现步骤和影响，不复制含凭据、内部地址或用户数据的完整日志。

## 网络诊断

工具支持时可观察：

- 请求是否发出；
- 状态码和耗时；
- 关键请求是否取消、超时或重复；
- 操作前后请求数量和目标类型变化。

默认不记录请求体、响应体、认证头或 Cookie。确需字段级核对时，先确认授权并只保留脱敏后的必要字段。

## 动态页面

- 懒加载：滚动后重新快照，记录触发位置和加载结果；
- 无限滚动：限定观察范围，不为“抓全”而无限请求；
- SPA 跳转：等待关键内容或 URL 状态变化，不只依赖网络空闲；
- 动画：等待稳定状态再截图；
- 实时数据：记录观察时间和刷新条件；
- A/B 实验：记录账号、会话或实验条件，不把单一变体当成全量规则。

## 页面比较

比较两个页面、版本或角色时保持：

- 相同视口和缩放；
- 相同语言和主题；
- 相同测试数据或等价状态；
- 相同操作路径；
- 独立会话，避免缓存和权限串扰。

输出结构差异、交互差异和数据差异，不只给像素差异比例。

## 未验证与受限项

以下情况必须明确写为未验证：

- 需要更高权限；
- 会改变真实业务数据但未获授权；
- 需要验证码或不可自动化的人机判断；
- 工具不支持 iframe、真机、网络或控制台诊断；
- 页面被反自动化策略拦截；
- 缺少可复现的数据状态。

“未观察到”不等于“不存在”。

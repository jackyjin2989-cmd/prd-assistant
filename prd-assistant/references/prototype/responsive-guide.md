# PC / H5 响应式实现规范

仅适用于用户明确要求双端或核心交互确需跨端表达时。只要求单端时不实现另一端。响应式是针对设备重新组织内容和交互，不是整体缩放。截图或设计稿存在时以目标材料为准，本文件只用于目标材料未覆盖部分的最小延展。

## 参考视口

实际视口按用户要求或目标材料确定：PC 常用 1440×900 / 1280×720；H5 常用 390×844 / 360×800。

## 核心原则

1. **内容重排，不是缩放**：不用 `zoom` 或 `transform: scale()` 做整体响应式。
2. **触控优化（H5）**：可点击元素触控区域不小于 44×44 CSS px，间距至少 8px，输入框高度至少 44px，不依赖 hover 作为唯一反馈。
3. **业务一致，呈现不同**：两端共享相同业务状态、数据规则和权限；差异只在呈现和操作方式。

## 组件适配对照表

| 组件 | PC 端 | H5 端 |
|------|-------|-------|
| 导航 | 顶部导航 + 左侧侧栏 | 底部 Tab 或汉堡菜单 + 抽屉；不用左右分栏侧栏 |
| 表格 | 完整列展示 | 列数 ≤6 横向滚动；7–12 卡片列表；>12 关键列 + 详情页 |
| 筛选 | 顶部筛选栏并排 | 折叠面板或筛选抽屉 |
| 表单 | 标签在左，两三列 | 单列，标签在上，输入框全宽，提交按钮固定底部 |
| 弹窗 | 居中模态框 | 底部抽屉（默认）；复杂表单用全屏页；简单确认用小弹窗 |
| 分页 | 底部页码 | 上拉加载更多 |
| 数据详情 | 左右分栏 | 进入新页面 |
| 操作菜单 | 行内按钮 + 更多下拉 | 更多按钮弹层或右滑操作 |

## 断点

- 大屏（≥1024px）：PC 布局；中屏（768–1023px）：侧栏收起为图标；小屏（<768px）：单栏 + 底部导航。
- 断点按内容调整：组件在 800px 放不下就在 800px 切换。

## 每个断点检查

- [ ] 无意外横向滚动条
- [ ] 文字完整可见，无截断溢出
- [ ] 按钮、链接可点击，无遮挡
- [ ] 弹层/抽屉适配视口
- [ ] 固定定位元素不遮挡内容
- [ ] 图片按比例缩放

## 实现技术

- 字体和间距用 `rem`/`em`；布局用 Flexbox 和 Grid。
- 断点用 `min-width`（移动端优先）或 `max-width`。
- 图片 `max-width: 100%`；用 `.pc-only`、`.h5-only` 控制显隐。

# 工具适配与能力降级

## 原则

本 Skill 描述的是浏览器观察能力，不绑定某一厂商或单一命令行工具。执行前先确认宿主实际提供的能力，不得因为文档出现命令示例就假设对应工具已安装。

优先级：

1. 宿主原生浏览器工具；
2. 环境中已经安装并获准使用的兼容浏览器自动化 CLI；
3. 用户提供的脱敏截图、录屏、导出文件和操作说明。

## 能力矩阵

| 观察意图 | 宿主浏览器常见能力 | 兼容 CLI 常见命令 | 不可用时降级 |
|---|---|---|---|
| 打开页面 | navigate | `open <url>` | 请求截图或录屏 |
| 查看标签页 | tabs list | `tab` | 单页执行并记录 URL |
| 获取结构 | snapshot | `snapshot -i` | 截图 + 用户说明 |
| 点击 | click(ref) | `click @eN` | 用户手动操作后重新观察 |
| 填写非敏感测试值 | type(ref) | `fill @eN "值"` | 用户手动填写 |
| 选择、键盘、拖拽、上传 | select/press/drag/upload | `select` / `press` / `drag` / `upload` | 记录未验证项；敏感操作需再次授权 |
| 等待 | wait for time/text/selector | `wait` | 短等待后重复快照 |
| 截图 | screenshot | `screenshot` / `screenshot --full` | 用户提供截图 |
| 读取属性或结构化数据 | get attribute/evaluate | `get attr` / `get text` / `eval` | 从快照人工提取 |
| 控制台诊断 | console messages | `console` / `errors` | 记录“环境不支持诊断” |
| 网络诊断 | network requests | `network requests` | 记录页面可见错误与时间点 |
| 用户接管登录 | handoff | headed browser + 用户手动登录 | 用户完成登录后提供截图 |
| 会话隔离 | tabs/context/session | `--session <name>` | 单任务单会话，完成后关闭 |
| 状态复用 | 宿主安全会话 | `state save/load` | 每次由用户重新登录 |
| 连接已有浏览器 | 宿主已有标签页 | `--auto-connect` / `--cdp` | 新建受控会话 |
| 代理 | 宿主网络设置 | `--proxy` / 环境变量 | 由用户或管理员配置，不绕过访问控制 |

命令名称只作为兼容工具的概念示例；执行时以当前工具帮助和宿主接口为准。

## 标准执行模式

### 打开并建立基线

```text
打开 URL → 短等待 → 获取快照 → 截取基线图
```

### 交互并验证

```text
使用最新快照中的元素引用操作 → 短等待 → 重新快照 → 记录变化
```

### 结构化提取

先获取快照。只有表格、链接或字段列表需要结构化输出且快照不足时，才读取 DOM 属性或执行只读脚本。不得使用脚本代替点击来绕过权限、校验或正常页面行为。

## 能力检查

开始前至少确认：

- 能否列出并选择浏览器标签页；
- 能否获取页面结构与交互元素引用；
- 能否截图；
- 能否让用户接管登录；
- 是否支持视口或设备模拟；
- 是否支持控制台和网络诊断；
- 是否支持会话隔离或状态复用。

缺少的能力写入观察记录。不得把“未验证”写成“无此行为”。

## 代理和已有浏览器

- 代理仅用于用户授权的网络环境、连通性或地域测试，不用于规避封禁、限流或访问控制。
- 代理凭据不得写入文档、命令示例、日志或仓库；优先由用户在环境中配置。
- 连接用户已有浏览器前应说明将读取哪些标签页；只操作用户指定页面。
- 不关闭、刷新或修改非本任务标签页。

## 平台限制

设备模拟不等于真实设备。只有当前环境实际支持模拟器或真机时，才能声称完成真机验证；否则只记录浏览器视口或设备模拟结果。

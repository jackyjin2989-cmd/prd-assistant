# PRD 语言表述规范

本文件只服务于 PRD 输出的语句通顺，不含写作、散文、润色场景，不打分。目标：语句通顺自然，读起来像 PM 给研发讲需求，同时保持需求文档的正式与严谨。

## 硬规则

1. 直接陈述：直说事实与规则，不铺垫、不宣告。删掉"为了……""值得注意的是""综上所述"这类开场。
2. 长短句交错：连续三个等长句就打断一个；短句说完一个点，长句展开条件与边界。
3. 具体优先：写数值、字段名、触发条件、报错文案；不用"合理""适当""相关""充分"。
4. 系动词优先：能用"是/有"就不用"作为、充当、标志着、扮演"。
5. 删套话动词：进行校验→校验；对……进行展示→展示；实现……的目标→直说目标；确保→删除或写成具体规则。
6. 删连接词：此外、同时、值得注意的是、由此可见——删掉后句意不变的就删。
7. 删强行对仗："不仅……而且……""不仅仅是……更是……"、三段式排比，改成一两句直陈。
8. 破折号从简：用逗号、句号断开，不靠破折号制造强调。
9. 一条规则只写一遍：同一规则在一处展开，其他位置引用，不做同义改写。
10. 不越界：不写第一人称、俏皮话、反问、抒情。正式不等于僵硬，允许"这个状态在下拉里筛不了"这种自然说法。

## 常用替换表

| 避免 | 改为 |
| --- | --- |
| 对……进行校验 | 校验…… |
| 对……进行展示 | 展示…… |
| 确保 | 删除，或写成具体规则 |
| 同步更新、统一修改 | 一并改、同时改 |
| 此外、同时、值得注意的是 | 删除 |
| 作为、充当、标志着 | 是、有 |
| 合理、适当、相关 | 具体数值或条件 |
| 本功能、该系统（无信息量重复） | 直称页面、列表、状态名 |

## 语气边界

- 该做的：像 PM 给研发讲需求——直接、具体、可执行
- 不该做的：机翻腔（英语语序、被动句堆叠）、公文腔（"现就……事宜通知如下"）、散文腔（抒情、比喻、升华）

## 自检

输出前出声读一遍，读着别扭的地方就是该改的地方。出现替换表左列的词，逐个替换或删除。

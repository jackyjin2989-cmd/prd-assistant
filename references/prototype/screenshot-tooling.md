# 宿主中立的截图执行契约

本文件定义已有能力如何安全取图、等待、测量及留证，不提供未经实测的平台命令。能力分类、验收判据和结论归 [visual-validation.md](visual-validation.md)；原型范围与资源底线归 [generation.md](generation.md)；配图和图文一致性归 [图片指南](../图片嵌入与截图指南.md)。以下所有截图、测量、重拍和批量动作都服从同一次能力判定，降级后不另开工具链。

## 执行前提

启动前通过当前工具说明和现有本地元数据核实以下条件，不运行来源不明程序来探测：

- 能力已存在且来源可信，能接收获准的本地 HTML，限制文件访问范围、隔离页面执行，并返回本次会话句柄。宿主工具可通过其已安装 browser driver 工作；不要求绕开驱动，但不得为截图自动安装、下载、升级或降级浏览器、驱动及依赖，也不改系统配置。
- 操作处于本次授权内；输入文件、执行脚本与资源已审查，未知外来 HTML 不直接执行。本地输入的真实路径须位于获准根内，不能靠路径编码、软链接或嵌套资源扩大访问。
- 使用本任务专属非持久化上下文或临时用户数据目录，不复用用户日常浏览器资料、登录态和已有标签页。核对工具实际提供的进程沙箱／宿主隔离，不能仅凭工具名或“无头”推定保护有效；临时上下文本身不是完整安全沙箱。
- 保持现有安全保护，不能通过削弱隔离来救截图。不能确认安全隔离、本地文件支持或访问范围时直接降级；不临时架设外网服务或改用用户桌面截图。
- 区分本地页面资源请求与宿主处理材料的数据路径。默认页面不主动外连；若任务要求零外连，还须现成能力在导航前阻断非授权请求并留记录，做不到就不作零外连承诺，若为硬约束则不启动。`file` URL、无头模式或请求记录为空都不能单独证明断网。

使用工具原生文件参数或标准 URI 转换处理空格、中文、`#`、`%`；不手拼路径、不为改名破坏相对资源基址。只有已有且获准的隔离本地预览能力可替代直接文件加载，并仍限制输入根和网络范围。

## 初次静态页探针

先用已审查、无外部资源和业务数据的最小本地静态页做一次端到端探针；可在获准工作目录生成此测试页，不携带用户敏感材料。页面含可辨识的静态标识；按下节就绪契约完成加载，用目标 CSS 视口与 DPR 截图，再按“输出与元数据”校验有效新图和读取能力，确认画面确为探针而非空白页或错误页。

只有静态页实际成功，才将候选能力报告为本会话可截图；工具名、版本响应或旧截图不算成功。记录真实平台与版本，不把本文件的方法表述为 Windows、macOS 或 Linux 已验收。交互支持还需在实际交付页执行状态入口和前后断言，不能从静态探针推出。

## 单页就绪与真实入口

为待验证页约定稳定、可读取的就绪信号：唯一 DOM 标记或工具可读取的结构化对象。信号至少包含协议版本、本次 run_id、page_id、state_id、status（pending／ready／error）；进入新状态先置 pending，异步数据、校验与渲染完成后再置 ready，失败置 error。静态页可由受控读取确认完成后产生同样记录，不假装页面实现了不存在的标记。

截图前同时满足：

1. 导航指向预期文件或真实状态 URL，页面与状态标识匹配；走真实控件时确认前置输入、禁用条件、点击可达性及操作前后断言。输入须经过真实输入事件，不能只赋值、改 class 或直接调用内部函数顶替交互。
2. 就绪信号属于当前 run_id 与目标状态；不把 load、网络空闲或定时器到期单独当作业务完成。
3. 等待 `document.fonts.ready`，并核对所需字体可用性、加载失败或回退；该 Promise 完成不保证指定字体全部成功。记录字体选择与已知回退，不能确认实际字体时标未知；关键图片完成加载与解码，图表完成绘制。
4. 等待范围内布局稳定；无持续变化页可比较连续两个渲染帧的关键矩形与滚动位置，容差事先声明。此检查只排除短暂抖动，不能代替业务 ready；对必要动画采用已确认的稳定取样状态，不通过随意改页造终态。
5. 收集有限、脱敏的页面错误、资源失败、工具返回状态；相关未捕获错误、断言失败或就绪超时不得当作成功。

提供查询状态只验证该状态呈现；主流程仍需实际鼠标／键盘入口验证。没有安全脚本执行能力时仅静态解析 HTML；现成 jsdom 可用于禁用脚本和外部资源的结构检查，但不是安全沙箱或布局引擎，不将来源不明脚本交给 Node 执行，也不以 DOM 构造成功代替功能验证。结构检查至少断言目标元素、文本和标签关联；功能检查另断言入口操作前后的状态、异步完成和错误结果，分别返回明确成功／失败，进程型适配将失败转为非零退出。

## 时限、重试与清理

- 开始前根据已确认的页面／状态／视口数量设置有限墙钟预算：发现与授权检查、启动、单页就绪及取图、首张有效图、整批和清理分别有上限。首图预算包含探针及可用重试；整批预算覆盖首图、每项验证、修正复查与清理，不因某图成功而重置。不设与任务范围无关的统一总时长或默认批量张数。
- 等待工具完成事件、显式 ready 和有效输出，不使用固定休眠。页面虚拟时钟不是进程墙钟期限；宿主超时后转后台也不是成功，须保留本次句柄并按期限收尾。
- 本任务**首次执行失败最多一次针对性重试**，不是每图一次：只在已有诊断指向可在原授权、隔离和预算内修正的问题时重试，并记录修正点。能力／权限／隔离缺失不重试；没有针对性措施则直接降级。不安装、不改系统、不切换工具链排障。
- 重试后仍失败，或后续再遇同类环境故障，停止相关批量动作并逐项标未验证；页面实现错误保留为未完成。修好实现后的视觉复查与环境重试不同，但同样受视觉指南的轮次和整批预算约束。
- 成功、失败、取消、超时都只使用**当前工具会话句柄**关闭本次页面／上下文／会话；共享浏览器由工具管理，不能关闭用户其他会话或按进程名称清理。工具不支持安全回收时不自行杀进程，报告受限并停止启动新实例。
- 仅在本次句柄确认关闭后清理本任务拥有的临时资源；所有权不明的目录、残留锁及用户进程不碰。保留必要的脱敏失败原因与工具状态；进程型接口记录退出码，会话型接口记录返回状态，不能吞掉错误后算成功。

## 输出与元数据

每次尝试使用唯一 run_id、attempt_id 和此前不存在的输出目标；文件在工具完成且校验成功前都不是可交付证据。失败重试用新目标，不读取上一次残留充数。

- **验证字节**：输出非空，按真实格式解析签名并成功完整解码，实际宽高符合截图模式。工具只返回图片引用但拿不到可校验字节时，记录证据缺口，不编造文件大小或哈希。
- **验证 fresh output**：输出绑定当前尝试和工具成功响应，创建／写入时间与本次窗口一致；有粗粒度时钟时结合唯一目标与返回标识校验，不仅凭存在或 mtime。读取实际字节计算 SHA-256，排除空图、半写入文件和旧产物。
- **绑定输入**：计算交付 HTML 与本次实际使用的本地资源、模拟数据的内容哈希；资源清单按规范化相对路径排序后汇总摘要。另绑定状态入口／操作、视口、DPR、缩放、字体、工具／浏览器版本、截图模式与裁切参数，不能只缓存文件名。
- **记录元数据**：协议版本、run_id／attempt_id、输入哈希、页面／状态、实际入口与操作、ready 结果、错误、CSS 视口、DPR、缩放、图片像素、滚动位置、输出路径／字节数／哈希、生成时间、实测系统／宿主／工具版本、字体与网络／隔离检查状态。未知字段写未知或 null，不补造。
- **发布与复用**：先校验再挂到交付引用。断点续跑必须匹配全部输入及参数摘要、核验已有图片哈希与解码结果；复用的是注明原 run_id 的历史证据，不伪报本次新截图。内容或参数变更使对应图片失效；无法重拍时按图片指南移除误导性引用并报告未覆盖状态。

## 测量、取景与批量

- 通过现成工具的受控页面读取获得结构化结果；若读 DOM，使用唯一结果节点并精确解析 JSON。核对协议、run_id、state_id、成功标志、字段类型与有限数值；不从页面标题、脚本源码或任意文本首个命中取数。
- 在同一次 ready 状态下读取 `getBoundingClientRect()`、计算样式、文本行盒、scroll/client 尺寸和实际滚动位置，注明坐标系；具体通过判据只见视觉验证指南，不在此另写字号或溢出阈值。
- 使用真实目标 CSS 视口及 DPR，核实工具实际应用值。优先目标元素截图；需裁切时依据当前元素边界、滚动偏移、DPR 和实际图片尺寸换算并验证，保留上下文全图。裁切／放大只辅助查看，不改变媒体查询布局，也不取代原图；插值图不用作像素基准。
- 定位检查先确认 fixed、sticky 或短页 footer 的模型，再选择初始、阈值附近、末尾和短页场景；记录滚动祖先与实际位置，同时检查占位、安全区及遮挡。长页分段按同一滚动坐标系确定位置，读取实际值，不能假定请求值不会被夹紧。
- 批量仅处理确认清单，每项明确页面、状态入口、前后断言、视口和输出；优先受控串行以简化资源管理，但不宣称浏览器只能单实例。共用同一预算和重试额度，成功项留证，失败／未执行项逐项标明，不拿默认态顶替。

## CSS 排查

1. CSS 变量检查实际作用域、继承、级联和 fallback，不只查根节点；未定义且无有效回退时声明可能在计算值阶段失效。能读取计算样式时核对最终值，无能力时仅报告静态判断。
2. `inherit` 不能作为 family 混入其他具体值组成 `font` 简写。可用合法的整体 `font: inherit`，或将 `font-family: inherit` 与字号、字重、行高长属性分开。
3. 卡片嵌套与扁平化是设计选择，不是通用错误；以已确认目标、层级和可读性决定，不以个人风格改版。修正后按同一能力判定复查，无能力则静态自查并保留未验证结论。

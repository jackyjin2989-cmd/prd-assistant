# 目标端与响应式实现

只覆盖已确认的平台与宽度范围，单端任务不扩成双端。范围和材料冲突以 [SKILL.md](../../SKILL.md) 为准，HTML 底线见 [generation.md](generation.md)；本文件仅定义内容适配。以目标材料和可读性为先，不用通用模式替换已确认结构或业务交互。

## 视口与断点

- 以实际 CSS 视口宽高测试布局，同时记录 DPR、缩放与截图像素尺寸；参考图片的像素宽度不直接等于 CSS 宽度。
- 例如 1440×900 或 390×844 只是可选 CSS 视口，不是默认双端验收矩阵。H5 必须使用真实目标布局视口；独立内嵌视口需记录其内层尺寸和测量对象，不能把 1400 宽桌面裁图当成 390 宽布局。
- 按内容最小可用宽度选断点，不固定套 768/1024。范围内检查断点两侧、最窄宽度和代表尺寸；范围外需求不自动增加。
- 不用 `zoom` 或 `transform: scale()` 做整体响应式；使用 Flexbox/Grid 重排，字号和间距可用相对单位，图片按比例缩放。

## 保持业务语义的候选方案

以下只供目标材料未覆盖处选用，不是组件强制转换表。选择时考虑字段最小宽度、比较任务、操作频率和状态恢复，而非只数列数。

| 组件 | 可选呈现调整 | 保持不变 |
|---|---|---|
| 导航 | 必要时折叠或用抽屉承载既有入口 | 信息层级、入口与返回关系；不默认新增底部 Tab |
| 表格 | 已声明的横向滚动，或经确认展示关键列 | 比较任务、必要字段与操作；不按列数直接改卡片／加详情页 |
| 筛选 | 换行、折叠或经确认使用抽屉 | 筛选值、提交时机、清空规则与返回后状态 |
| 表单 | 多列改单列、标签移到上方 | 字段、校验与提交结果；固定提交栏需检查遮挡 |
| 浮层 | 调整尺寸、位置、内部滚动与碰撞回退 | 模态性质、关闭规则与焦点；不默认改底部抽屉或新增页面 |
| 分页 | 页码精简、换行或调整控件位置 | 分页、页码恢复与排序；不自动改为无限滚动或上拉加载 |
| 详情与操作 | 重排现有区块，保持必要操作可见可达 | 不无依据新增详情路由、侧滑操作或隐藏核心操作 |

## 触控与阅读

- 可将 44×44 CSS px 触控区域、相邻目标约 8px 间隔作为增强设计目标，不把它们说成所有等级的强制标准；WCAG 2.2 AA 的 24×24 目标尺寸还涉及间距、等价控件、行内等例外，不能据尺寸单项宣称整体合规。
- 不依赖 hover 作为唯一入口；输入、按钮、展开控件须可通过键盘操作并保留可见焦点。完整 HTML 与焦点要求引用 generation.md，不另定标准。
- 先按目标材料与可读性确定字号及允许折行；优先重排或允许换行，不为塞成单行无限缩字。禁止禁用用户缩放；放大文字后仍能获得内容和操作。
- 显隐处理不得留下不可见却可聚焦的控件，不能仅为适配删掉已确认的信息。

## 范围内检查

- 区分预期滚动与意外溢出，滚动内容可达且有可发现的操作方式。
- 核对文字折行、裁切、图片比例、控件遮挡、焦点与触控可达。
- 检查浮层有效可见边界、固定元素占位及软键盘／安全区影响；具体通过判据只在 [visual-validation.md](visual-validation.md) 定义。
- 截图和测量服从 [screenshot-tooling.md](screenshot-tooling.md) 的就绪与证据契约；没有现成能力就降级，不为覆盖端型安装环境。

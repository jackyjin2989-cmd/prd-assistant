# 网站与截图参考流程

## 授权边界

只观察公开页面或用户明确授权访问的页面。登录、验证码和多因素认证由用户操作。禁止保存会话凭据、导出 Cookie、绕过访问控制或抓取不必要的个人数据。

## 模糊截图后的授权登录观察

1. 先判断截图是否足以识别信息架构、布局、组件、状态和交互；能完成任务时不访问网站。
2. 无法辨识的文字、字段值和规则标为“待确认”，不得通过猜测补齐。
3. 仅当缺失信息会影响原型结构或关键交互时，向用户说明需要观察的目标网站、具体页面和目的，并取得明确授权。
4. 打开授权页面后，将浏览器控制权交给用户完成登录、验证码或多因素认证；不得要求用户在聊天中提供凭据。
5. 用户交回控制权后，只观察获授权的必要页面和状态；不打开账户、安全、账单、成员等无关区域，不下载数据，不导出 Cookie 或存储会话。
6. 记录抽象布局与交互规律；遇到姓名、头像、邮箱、手机号、组织名、订单号、内部地址等信息，先遮蔽或以虚构值替换，再截图或写入笔记。
7. 观察结束后，不复用登录态处理其他任务；交付中注明观察范围、脱敏动作和未观察区域，不包含凭据、真实数据或受限制资产。

## 观察清单

按页面记录，不复制源码：

- 信息架构：入口、导航、页面层级；
- 布局：容器宽度、栅格、留白、固定区域；
- 组件：表单、列表、卡片、弹层、反馈；
- 状态：加载、空、成功、失败、禁用、权限不足；
- 响应式：断点、折叠方式、内容优先级；
- 交互：触发、反馈、完成条件和恢复路径。

## 脱敏

截图或笔记中的姓名、邮箱、手机号、头像、地址、订单号、组织名和内部域名均替换为虚构值。只保留实现所需的结构信息。

## 原创转译

将观察结果转化为原则，例如“窄屏将侧栏折叠为抽屉”，而不是复制特定站点的尺寸、文案或视觉资产。对布局、配色和组件进行原创设计，使结果服务于当前产品任务。
